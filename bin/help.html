Hydroscope Manual

Model and observsational data

Error metrics and statistics are compared between model and observation data. To load model or observational data click the button beside the "File:" label. You can load a .csv or .nc file. The file must have a time or date index. This means for a csv file the first column must contain proper dates or times. For a netcdf file one of the dimensions must be time. There can be lots of other columns or variables.

Variable

After loading files you must select the variable you are interested in. The variables founds are in the "Variable:" dropdown box.

Dimensions

For a NetCDF file variables can have more than just a time dimension. You must select the dimension using the Dimensions button. A csv file cannot contain dimensions (currently the only dimension is time in the first column), so you don't have to click the Dimensions button. Selecting Dimensions can be a bit fiddly because a dimension might have a lot of possible values. If there are only a few possible values, they are listed in a dropdown box, so you can just select them. If there are a lot of values, then you are going to have to type one in, so you will have to know your data before using this tool.

View

The View button can only be used after selecting your File, Variable, and possibly Dimensions. The presented graphics are simplistic, this is not a plotting program, and the View button is just for you to confirm that you have selected your correct Variable/Dimensions.

Purpose and metrics

Here you can select the purpose of your model, which then populates the metrics dropdown box with appropriate metrics. Not all metrics make sense for a given purpose. After selecting your metric you can push the Calculate button to generate the result

Results

Any output from Calculating a metric will appear here.

Updating

Upon startup, github is checked to see if there is a newer version available, if so, you are prompted to see if you want this new version. It might take a few minutes to download and the install started.

Optionally you can go to Help -> Upgrade and will be presented with:

  • Version of the currently running program
  • Version of the code on github, this will likely be at least as new as your running program
  • A list of installable versions found on github. These will likely include some older versions and something close to the code version on github, but might be a bit older because an installable version does not have to be generated everytime the code is updated on github
You can click on an installable version, and after some time, the download will start and the install started.
